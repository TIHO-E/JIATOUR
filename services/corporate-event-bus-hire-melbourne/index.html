Build the journey around your event

Start with the time guests need to be at the venue, rather than just a preferred pickup time. Include registration, presentation or dinner start times, along with the planned finish. For events running across several days, send a separate outline for each day so the team can review the full transport requirement.

Organise hotels and collection points

Let us know whether your group will leave from one office or hotel, or whether there are several proposed pickup points. Include street addresses and any venue instructions for coaches. If people will return to different locations, explain the expected groups and timing so the route can be considered before a quote is confirmed.

Choose for passengers and equipment

The listed fleet options range from 7–14 seats to 24, 34 and 57 seats. Include luggage, presentation materials or event equipment in your enquiry, because seating capacity alone does not establish storage space. Tell us about access requirements and your event organiser’s contact details when discussing the journey.

BEFORE YOU GO

Good to know

A few details to help you plan.

Can we request several pickup locations?

Include each proposed pickup address and the number of passengers at each stop. Jia Tour will discuss the route, timing and availability before confirming arrangements.

What if the event finish time is uncertain?

Tell the team your expected finish time and explain what may change. Agree on collection arrangements directly with Jia Tour before the booking is confirmed.

Can I request transport over several event days?

Yes. Send the dates, locations and daily timetable together so Jia Tour can review the complete request and discuss a quote.
